# Курсовая работа: Отслеживание самолетов в воздушном пространстве стран

Моя курсовая работа по модулю "API и библиотека requests". Программа получает данные о самолётах в реальном времени через API OpenSky Network и Nominatim (OpenStreetMap).

## Что умеет программа

- 🌍 Запрашивать координаты стран через Nominatim API
- ✈️ Получать список самолётов в воздушном пространстве страны через OpenSky API
- 📊 Показывать топ N самолётов по высоте полёта
- 🔍 Фильтровать самолёты по стране регистрации
- 💾 Сохранять данные в JSON-файл
