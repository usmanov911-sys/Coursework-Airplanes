# ✈️ Курсовая работа: Отслеживание самолетов в реальном времени

Моя курсовая работа по модулю "API и библиотека requests". Программа получает данные о самолётах в реальном времени через внешние API, обрабатывает их с применением принципов ООП и предоставляет удобный консольный интерфейс для анализа.

## 🚀 Возможности программы

- 🌍 **Геокодирование:** Автоматический запрос координат границ страны (bounding box) через Nominatim API (OpenStreetMap).
- ✈️ **Мониторинг:** Получение актуального списка самолётов в воздушном пространстве выбранной страны через OpenSky Network API.
- 📊 **Аналитика:** Вывод топ-N самолётов по высоте полёта (с сортировкой по убыванию).
- 🔍 **Фильтрация:** Поиск самолётов по стране их регистрации.
- 💾 **Персистентность:** Сохранение и загрузка данных о полётах в локальный JSON-файл.

## Принципы ООП и SOLID в проекте

В ходе работы я сознательно применил следующие принципы:
1. Наследование и Абстракция: Классы FlightAPIClient и JSONStorage наследуются от абстрактных базовых классов (BaseAPIClient, BaseStorage), что задаёт строгий контракт для их реализации.
2. Инкапсуляция: Класс Aeroplane самостоятельно валидирует входящие данные в методе __init__ (например, преобразует None в 0.0 для корректной работы сортировки).
3. Полиморфизм: Реализованы магические методы __lt__ и __gt__, что позволяет сравнивать объекты самолётов между собой и использовать встроенную функцию sorted().
4. Принцип единственной ответственности (SRP): Каждый класс отвечает только за свою задачу (модель, API, хранение, UI).
5. Принцип открытости/закрытости (OCP): Архитектура позволяет добавить новый тип хранилища (например, CSVStorage или базу данных), не изменяя код основного приложения.
